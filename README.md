# 📌 Project Overview

This repository demonstrates a comprehensive implementation of the **TestNG Framework**, one of the most widely used testing frameworks for Java-based automation.

The project covers the core building blocks required to design scalable automation frameworks, including **TestNG annotations, DataProviders, assertions, grouped execution, test lifecycle management, and suite execution**.

Rather than focusing only on writing test methods, this repository highlights the architectural concepts that form the foundation of enterprise Selenium and API automation frameworks.

# ⭐ Framework Highlights

### ✔ TestNG Framework

Implements TestNG as the primary testing framework for automation.

Supports modular, maintainable, and scalable test execution.

---

### ✔ TestNG Annotations

Demonstrates complete lifecycle annotations including:

- @Test
- @BeforeSuite
- @AfterSuite
- @BeforeClass
- @AfterClass
- @BeforeMethod
- @AfterMethod
- @Ignore

---

### ✔ Data-Driven Testing

Implements TestNG DataProviders for executing the same test with multiple datasets.

Benefits include:

- Improved reusability
- Better test coverage
- Reduced code duplication

---

### ✔ Assertions

Demonstrates both assertion strategies:

- Hard Assertions
- Soft Assertions

Helping validate application behavior effectively during automation.

---

### ✔ Test Suite Execution

Supports execution through:

- Individual Test Classes
- testng.xml
- Suite-based execution

---

### ✔ Factory Pattern

Includes TestNG Factory examples demonstrating dynamic test object creation and flexible execution.

---

### ✔ Maven Project

Dependency management using Maven for consistent builds and simplified project maintenance.

---

### ✔ HTML Reports

Automatically generates TestNG execution reports after each test run.

# 🚀 Running the Framework

## Clone Repository

```bash
git clone https://github.com/ArpitChoubey/TesTNG-framework-Implementation-For-Automation.git
```

---

## Install Dependencies

```bash
mvn clean install
```

---

## Execute Test Suite

```bash
mvn test
```

or execute

```
testng.xml
```

directly from Eclipse or IntelliJ IDEA.
